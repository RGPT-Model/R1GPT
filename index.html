Our current open model

A research model.
A first step.

R1GPT v2 is a compact PyTorch language-model experiment trained on WikiText with a custom BPE tokenizer. It predicts text continuations; it is not instruction-tuned or a general-purpose assistant.

R1GPT v2 is an educational, local model; it does not power a live hosted API.

Useful to know

A few clear
answers.

Can I use RGPT's API today?

Not yet. Hosted inference and API keys are planned, but not live. You can run the research model locally using the public repository, on your own hardware.

What can I use today?

The repository contains a small next-token language-model experiment and a Python command-line workflow. It is not instruction-tuned, and its generated text should be treated as a research output, not a reliable assistant response.

Will there be free or low-cost API access?

That is our goal: a free way to get started and affordable access for students and builders. There are no published prices or plans, and hosted API access is not live yet.

Are my prompts or attachments stored?

This static website does not transmit prompt text or attachments. Files are only selected in your browser and are not uploaded. Avoid entering sensitive information into any unconnected prototype.

How can I follow development or report an issue?

Visit the public GitHub repository for source, setup instructions, and project discussions. Use GitHub Issues for bugs or suggestions.

RGPT is an LLM company focused on building language models and accessible tools that help students and builders turn ideas into working projects.
